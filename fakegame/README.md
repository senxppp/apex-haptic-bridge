# 假游戏桩

引擎按**进程名**匹配游戏：没匹配到，它就不进"游戏进行中"的震动模式。手上没游戏时，
用它来让引擎以为有游戏在跑。

## 用法

```bat
build.bat ForzaHorizon5.exe
ForzaHorizon5.exe "C:\Windows\Media\Alarm01.wav" 600
```

- 第一个参数：编出来的文件名，**要跟引擎里已有的游戏配置对得上**（随便起名匹配不到）
- `wav`：循环播放的音源，用系统自带的最省事
- `秒数`：存活时长，默认 3600

## 注意

- 只用于**本地验证链路**，不要拿它去糊弄在线游戏或刷时长。
- 编译产物（`.exe`）在 `.gitignore` 里，不随仓库分发——到哪台机器就在哪台机器编。
- 名字跟真实游戏一样，所以**别把它丢进 Steam 的游戏目录**，容易和真游戏混起来。
